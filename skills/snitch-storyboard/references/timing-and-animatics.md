# Timing and animatic verification

Read for runtime constraints, dialogue, sound cues, or any animatic request. Distinguish
three levels of evidence:

1. **Desk estimate:** action phases and selected shot intervals add to a target duration.
   Plausibility is reasoned, not measured.
2. **Timed read/rehearsal or assembled rough playback:** specific dialogue or action was
   timed. State the version, method, and what was included.
3. **Inspected animatic:** actual boards or placeholders were placed on a playable timeline.
   State artifact, inspected interval, runtime, frame rate if known, temp audio state, and
   unresolved effects/performances. Playback can validate rhythm and reveal order but does
   not guarantee final animation, exposure, audio mix, or audience response.

## Account for screen time

Use `selected shot ID | timeline in–out | duration | action phases | dialogue/audio cue |
transition | verification state`. Adjacent selected intervals must cover the requested
sequence, with no unexplained gaps or double counts. A shot's panels occupy moments *inside*
its interval. A five-second shot with three panels is still five selected seconds. Handles,
alternate coverage, setup time, and shoot order are separate. A sound lead can start under
the preceding image; a tail can continue under the next. A dissolve or split-screen
overlap is one elapsed interval on the final timeline.

Speech, action, and reactions need believable room. For a desk estimate, use a clearly
stated provisional delivery assumption rather than forcing protected lines to fit a label.
When actual reads or footage exist, prefer their timings. If protected dialogue or a
required visible beat cannot fit the hard target, show the conflict and present conditional
shortening, staging, or runtime changes for approval. Do not speed up silently.

For an action-heavy scene, time entry/anticipation, decisive movement, result, and audience
recognition separately where needed. Static board images can hide the difficulty of
performing a transition; identify moves that need an animation test or rehearsal. For
fast editing, test the sequence at intended viewing size so a prop or pose is not present
for only an unreadable instant.

## Actual animatic handoff

If media tools are available and the request authorizes playback creation, build from the
selected panel order. Use blank/placeholders with explicit IDs only when images are unavailable;
call the result a placeholder animatic, not rendered boards. Keep audio tracks labeled as
temporary, silent, or absent. Inspect the output, measure its actual duration, and report
which intervals were played or sampled. If the host cannot generate or inspect playback,
give a precise animatic *specification* and mark the actual runtime unverified. Never
claim a table, slideshow outline, or list of image prompts was played.
