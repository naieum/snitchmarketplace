## CATEGORY 24: Memory Leaks — deprecated

A leaked listener or an unbounded cache is a reliability defect, not attacker impact, and this
skill's own description excludes general code review unrelated to security. Nothing replaces it
here; a profiler or a general code-review tool is the right instrument.

**Do not scan this file.** If category 24 is selected, say the category is deprecated and offer the active categories instead.
