# Plan, then build

For the request: **$ARGUMENTS**

1. Explore the relevant code/context first — do not start editing.
2. Brainstorm 1–3 approaches and note trade-offs.
3. Present a short, concrete plan: files to touch, the approach, and risks.
4. **Stop and ask for approval before writing any code.**
5. After approval, implement, then verify against the project's feedback loop
   (tests/screenshots — see CLAUDE.md).
