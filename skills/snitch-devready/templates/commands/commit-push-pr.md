# Commit, push, PR

1. Review the working tree (`git status`, `git diff`).
2. Infer the repo's commit-message style from recent `git log` and match it.
3. Stage, commit, create/switch to an appropriately named branch, and push.
4. Open a pull request with a concise summary of what changed and why.

If this is the first commit (greenfield), initialize git if needed and make a
sensible initial commit instead of a PR.
