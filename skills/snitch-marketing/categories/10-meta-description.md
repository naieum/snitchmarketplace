## CATEGORY 10: Meta description

`<meta name="description">` is the page's pitch to the SERP. Google doesn't directly use it as a ranking signal, but it's almost always what gets shown as the snippet under the title, which controls CTR. A missing or generic meta description means Google generates one from page content, often picking a sentence that doesn't sell the click.

### Evidence required (do not skip)

**Source mode, required tool calls:**

1. `Glob` every route file. `Read` each + its parent layouts.
2. `Grep` for `description:`, `meta_description`, `<meta name="description"`, `<meta name='description'` across the project. Quote each match with file:line.
3. For each indexable route: confirm the description string. Quote it. Check it against the route's actual content (read 30-50 lines of the page's primary content) for relevance.
4. For "duplicate descriptions" findings: bucket by exact description string, quote at least 3 routes per bucket.

**Crawl mode, required tool calls:**

1. `Fetch` URL. Quote the `<meta name="description">` element verbatim.
2. For duplicate-description findings: fetch up to `crawl-max-pages`, bucket by string, quote.
3. For "Google generated its own snippet" findings: this requires comparing to actual SERP results, which is out of scope for static crawl. Note in report when description is short/generic and likely to be overridden by Google.

### Forbidden claims

- "Most pages don't have meta descriptions." Enumerate; quote count.
- "The descriptions are generic." Quote at least 3 to show the pattern.
- "Google probably rewrites these." Don't speculate; if the description is sane (50-160 chars, page-specific), state it as fine.

### Detection

#### Source mode

- **Next.js App Router**: `metadata.description` in `layout.tsx` / `page.tsx` exports OR `generateMetadata` returns.
- **Next.js Pages Router**: `<meta name="description" content="..." />` inside `<Head>`.
- **TanStack Start**: `head: () => ({ meta: [{ name: 'description', content: '...' }] })`.
- **Astro**: `<meta name="description" content={description}>` in layout's `<head>` slot.
- **Remix**: `meta` export returning `[{ name: 'description', content: '...' }]`.
- **WordPress**: theme `header.php` OR Yoast / RankMath per-post overrides.

#### Crawl mode

`Fetch`. Look for `<meta name="description">` in `<head>`. Quote.

### What to Search For

- `name="description"`
- `name='description'`
- `description:` (object property style)
- `meta_description` (WordPress)
- `_yoast_wpseo_metadesc` (WordPress Yoast)

### Actually Hurts SEO

- **No meta description on indexable page**.
  Evidence required: route file or rendered HTML showing absence of the meta tag. Quote.
- **Same description across multiple pages**.
  Evidence required: bucketed routes with the duplicate string quoted.
- **Description >160 chars (truncated in SERP)**.
  Evidence required: exact length count + the description text.
- **Description <50 chars (insufficient pitch)**.
  Evidence required: exact length + the description text.
- **Description set to a framework default** (`Generated by create-next-app` etc.).
  Evidence required: the description AND the framework default it matches.
- **Description that doesn't reflect page content**.
  Evidence required: the description AND a quoted excerpt from the page's H1/intro that contradicts it.
- **Description keyword-stuffed**.
  Evidence required: the description text + the repeating tokens.

### NOT a Problem

- Brand-tagline as description on the homepage. Acceptable.
- Description 155-165 chars (slightly over, but most clients display the truncation gracefully).
- Description for a page intentionally noindex'd. Doesn't matter.
- Long-form blog post with no meta description IF the article's first paragraph is naturally pitchy (Google picks it as the snippet, often well).

### Context Check

1. Indexable? Don't flag missing on noindex'd pages.
2. Auto-set by SEO plugin? Check Yoast/RankMath settings + rendered HTML.
3. Computed from CMS data? Check the data source for empty/null cases.
4. Is the description identical to the title? Wasted opportunity; should add detail. Flag as Medium.
5. Brand suffix patterns ("...| My Brand")? Acceptable but eats SERP pixels; prefer descriptions that pitch in their own characters.

### Reference

Google's documentation on snippets: https://developers.google.com/search/docs/appearance/snippet

**Severity tagging:**
- No description on indexable page → High.
- Framework default description → Critical.
- Same description on >5 pages → Critical.
- Same description on 2-5 pages → High.
- Description doesn't reflect content → High.
- Description >160 or <50 chars → Medium.
- Description keyword-stuffed → Medium.

**Fix voice:** `plain-language-designer` (primary) | `honest-design-critic` (backup).

Read `souls/plain-language-designer.json` before writing the Fix. Plain-language commercial writing: say what the page is, why someone clicks it, in one breath.

Worked fix example:

> The description's job is to make a person scrolling SERP results stop and click YOUR result instead of the seven others. So write what the page actually does for them. Not what it is. What it does.
>
> Bad: "Snitch is a security audit tool for AI-built code." (true, generic, sells nothing)
>
> Good: "Run a 69-category security review on your AI-written code in Claude Code, Cursor, or Copilot. Bring your own model. Every finding proved with file:line evidence." (specific, says what's in it for them)
>
> ~150-160 chars, page-specific, no fluff, no brand-as-suffix unless the brand IS the pitch.
