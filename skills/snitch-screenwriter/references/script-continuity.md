# Script continuity and production constraints

Load this Reference for multi-scene drafts or revisions with recurring state.

Use a ledger with `scene ID | time relative to previous | character knowledge and goal |
location and access | prop/costume state | rule or promise changed | next dependency`.
Record states later scenes rely on. A prop's color matters when recognition or matching
matters; its owner, position, damage, or contents matter when those drive action. Track
revelations by who learns them, not just when the audience learns them.

When a later scene appears to contradict an earlier one, test whether an off-screen
transfer, time jump, lie, or withheld fact was established. If not, propose the smallest
on-screen setup or revise the later action. Do not silently invent an off-screen event
to declare the draft consistent. Separate an objective state claim from a character's
belief: an accusation can be wrong or rash without breaking continuity. If the supplied
scope ends before an unexplained theft, disappearance, or reversal can pay off, record a
conditional story question or Skip for the missing later material. Make it a Finding only
when the current text itself requires an impossible state or a protected causal link has
already failed.

Production limits are story constraints when supplied. For a cast/location ceiling or
inaccessible action, offer a version preserving the dramatic function with available
resources, and name any lost effect. Label proposed locations, effects, or extras not
established as available. Pages cannot prove a location permit, performer availability,
effect cost, or shot feasibility.
