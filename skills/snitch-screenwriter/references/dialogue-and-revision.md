# Dialogue and revision

Load this Reference for substantial dialogue or a supplied scene revision.

Dialogue is an action a character takes toward someone, not a transcript of everything
the writer knows. Give each speaker a current aim and a reason to say or withhold a line.
Distinguish voices by priorities, vocabulary, rhythm, and what each notices; a repeated
verbal tic alone is not characterization. Subtext arises when literal words and visible
behavior pursue different aims. Direct speech is often right when a character would
actually say the thing; obscurity is not automatically depth.

Read the scene aloud in the intended language when possible. A desk read checks clarity
and rough duration; it does not predict a performance. Preserve pauses or overlapping
speech where timing and action matter. If a visual action conveys the same fact, decide
which carrier should dominate rather than doubling every point in dialogue.

For revisions, diagnose before rewriting. Identify the requested change and protected
lines, plot facts, relationships, and downstream scenes. Make the smallest revision that
fixes the demonstrated failure. A new line may change a knowledge state or motive later;
record that dependency. Show a before/after excerpt or change ledger when it helps the
user assess the edit. Do not smooth away intentionally awkward, regional, or
character-specific speech merely to make all characters sound alike.
