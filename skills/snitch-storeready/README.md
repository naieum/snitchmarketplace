# snitch-storeready v0.3.1

App store submission readiness audit for Apple App Store and Google Play — review guidelines, privacy manifests / Data safety, SDK/API floors, permissions, billing, metadata — with file:line evidence for everything checkable from code. Web apps with no native target get a store-path feasibility assessment (Capacitor / TWA / React Native) instead of a dead end.

Canonical source: the snitchskills repo. This copy is the marketplace distribution.
