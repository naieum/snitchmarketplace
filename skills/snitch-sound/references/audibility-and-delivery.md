# Audibility and production reality

Load when the request depends on dialogue clarity, available recordings, a target format,
or an audit of actual audio.

- Put the information hierarchy in words before choosing processing: essential dialogue,
  essential event, context, then optional texture. If the story intentionally hides a word
  or event, record that protected choice instead of treating it as a repair target.
- State when ambience, effects, or music should make room for speech. Do not assert an
  intelligibility result without listening on the intended playback context.
- For live action, distinguish production dialogue, room tone, wild lines, Foley, and
  effects that still need recording. For animation, identify required voice performances
  and designed events. Never assume a source has been captured or cleared for use.
- Match perceived space to story geography: distance, reverberation, obstruction, and
  perspective changes. A cut to a different viewpoint does not automatically move the
  underlying world source.
- Ask for actual delivery requirements before specifying channels, loudness, true peak,
  stems, or accessibility deliverables. A rough mix suggestion is not a compliance test.
- For an audit, listen to the supplied audio; cite file and time span. Waveform appearance
  alone cannot establish audibility or intelligibility. If playback or target information
  is unavailable, use Skip for that claim and report only text-proven contradictions.
